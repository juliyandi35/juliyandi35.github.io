# Nalarata

Landing page jasa olah data, konsultasi riset, dan tutoring oleh Juli Yandi Rahman, S.Mat.

Situs statis: `index.html`, `styles.css`, `script.js`, dan `assets/`. Tanpa build step.

Pratinjau lokal: jalankan `python -m http.server 8000` di folder ini, lalu buka http://localhost:8000.

Branch ini berdiri sendiri dan tidak berhubungan dengan portofolio di branch `main`.

Catatan sebelum dipublikasikan: nomor WhatsApp ada di atribut `data-wa` pada `<body>` dan di tautan `wa.me` di `index.html`. Font dimuat dari Google Fonts.
